# 🌱 نَبْت | NABT

منصة عربية RTL لإدارة الحضور والكتب والتقدم لدى مجموعة تعليمية صغيرة.

## التقنيات
React 19 + TypeScript + Vite + Supabase PostgreSQL / Auth / RLS. الواجهة متجاوبة، مع تهيئة PWA أولية.

> تنبيه: المستودع يستخدم حاليًا TypeScript 5.9 وVite 7؛ ترقية الإصدارات المستهدفة 7 و8 على التوالي تحتاج التحقق من توافق الحزم والبناء، ولم تُنفّذ بعد.

## التشغيل
1. ثبّت Node.js 22 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` (المفتاح الموجود في الملف **publishable** ومخصص للواجهة وليس سرًا).
4. نفّذ `npm run dev`.
5. في Supabase Auth أضف مستخدمات عبر المسار الإداري المناسب. عند إنشاء مستخدمة يُنشأ ملف profile بدور member. لتعيين المديرة الأولى استخدم SQL Editor بإجراء إداري موثوق؛ لا تمنح دور director من واجهة التسجيل العام.
6. شغّل `npm run build` قبل النشر.

## الحالة الحالية
- ✅ قاعدة بيانات حقيقية بها profiles, books, sessions, attendance، ومفعّل عليها RLS.
- ✅ تسجيل الدخول وكشف الدور وعرض المكتبة وملخص الحضور.
- ✅ تسجيل جلسة جديدة مع حضور/غياب كامل للعضوات، ومنع إنشاء جلسة مكررة بحسب فحص الواجهة وقيود SQL.
- ✅ إضافة الكتب من حساب المديرة.
- ⏳ تعديل سجلات الحضور، سجل التدقيق، إنشاء حسابات العضوات من لوحة الإدارة، التصدير والتقارير التفصيلية.
- ⏳ إرسال Push Notifications (غير مفعل)، أيقونات الشعار الأصلية للـ PWA ومراجعة تثبيت التطبيق.
- ⚠️ تسجيل الجلسة وحفظ الحضور عمليتان منفصلتان حاليًا. في حال فشل الحضور بعد إنشاء الجلسة لا تعيدي إنشاءها. سيتم تحويلها إلى RPC ذرية في المرحلة التالية.
- ⚠️ لم يتم تأكيد نجاح build بعد لعدم توافر تثبيت الاعتماديات في بيئة التنفيذ.

## الأمان
- لا تحفظ مفاتيح `service_role` أو `sb_secret` أو أسرار Web Push في ملفات React أو GitHub.
- `.env` مستثنى من Git.
- عند النشر استخدم HTTPS وحدد Site URL في Supabase Auth.
